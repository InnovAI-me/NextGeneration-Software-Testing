Large language models (LLMs) are increasingly embedded in autonomous and
self-adaptive software-testing pipelines, spanning unit-test generation,
GUI exploration, bug reproduction, flaky-test triage, fuzzing, and REST
API testing, promising to automate activities long considered to
require human judgment. Despite rapid growth, the literature is
fragmented across techniques, benchmarks, and claims of effectiveness,
with several influential results later shown to be overstated once
rigorously re-evaluated, making it difficult to assess the genuine
state of agentic AI in quality engineering. This systematic literature
review (SLR), following Kitchenham and PRISMA guidelines, screens
\textit{[N\_INITIAL]} candidate studies drawn from
\textit{[DATABASES]} (\textit{[START\_YEAR]}--\textit{[END\_YEAR]}),
with 31 priority studies analyzed in depth across technique categories
including surveys, unit-test generation, multi-agent/agentic test
generation, agentic software-engineering foundations, bug
reproduction/validation, mobile and GUI testing agents, test oracles,
CI/flaky-test triage, API testing, LLM-based fuzzing, and agent
security. We find that multi-agent architectures and coverage-guided
feedback loops consistently improve test quality over single-shot
prompting, but the test-oracle problem, cross-language/cross-scale
generalization, fault-detection validity, context management for large
codebases, and agent security remain substantially unresolved; several
widely cited ``state-of-the-art'' results do not hold under corrected,
leakage-free evaluation. We conclude that advancing truly autonomous
software testing requires rigorous, contamination-resistant benchmarks,
fault-detection-centric (not coverage-centric) evaluation, and
dedicated attention to agent robustness, security, and developer trust
alongside continued architectural innovation, and we outline a
corresponding research agenda.
